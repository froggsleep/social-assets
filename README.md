# social-assets

Images and videos attached to @sleepyfroggggg Threads posts. The Threads API fetches
media from a public URL, so every attachment lives here.

```
https://cdn.jsdelivr.net/gh/froggsleep/social-assets@<commit>/<image|video>/<slug>-<YYYYMMDD>.<ext>
```

- Only publish-approved assets go here. Drafts stay local.
- Images: JPEG or PNG, width 320–1440px, 8MB max.
- Videos: MP4 (H.264, yuv420p).
